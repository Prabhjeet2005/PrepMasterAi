# 🛡️ PrepMaster AI
**Enterprise-Grade Automated Proctoring & AI Interview Platform**

PrepMaster AI is a highly scalable, full-stack application designed to secure Online Assessments (OAs) and conduct intelligent, voice-based technical interviews. Built to solve the real-world constraints of remote hiring, it utilizes a dual-device WebRTC architecture, Edge-based Computer Vision, Digital Signal Processing (DSP) for audio anomalies, and an LLM-driven conversational interviewer.

---

## 🚀 Technical Highlights

* **Dual-Device Security Perimeter:** Synchronized desktop and mobile camera feeds via WebSockets.
* **Zero-Latency Edge AI:** Computer vision models (`face-api.js`, `coco-ssd`) run entirely client-side, eliminating server-side rendering costs and latency.
* **Decoupled Cloud Storage (S3-Pattern):** Heavy proctoring evidence (Base64) and Resume PDFs are routed to a Cloudinary CDN, preserving MongoDB document limits.
* **Remote Code Execution (RCE):** Sandboxed C++ compilation and execution against hidden test cases.
* **Generative AI Interviews:** Real-time, voice-to-voice technical interviews dynamically generated by parsing candidate resumes.

---

## 🧠 Deep-Dive Feature Architecture

### 1. Dual-Camera Edge AI Vision Engine
Instead of relying solely on a laptop webcam (which can easily be bypassed), the system forces the user to connect their mobile phone as a secondary camera via a secure socket room.
* **Face Identity & Tracking:** Utilizes `TinyFaceDetector` to lock onto the candidate's facial geometry. Calculates Euclidean distance dynamically to detect unauthorized replacements, multiple faces in the frame, or prolonged looking away.
* **Hardware-Accelerated Object Detection:** Leverages `coco-ssd` forced into 720p HD resolution to accurately detect forbidden items (cell phones, books) in the candidate's hands or workspace.
* **Tiered Leniency System:** Implements a state-machine warning system. Soft UI warnings are issued for minor posture issues, reserving hard strikes and snapshot captures for undeniable infractions to prevent false positives.

### 2. Audio DSP & Acoustic Anomaly Detection
Traditional proctoring fails against whispering or off-camera assistance. PrepMaster solves this using the native Web Audio API.
* **Dynamic Ambient Calibration:** The system listens to the room for 5 seconds before the test begins to establish a custom baseline noise floor.
* **Signal-to-Noise Ratio (SNR) Analysis:** Detects human speech by identifying frequency spikes (+15 SNR) that pierce the background noise.
* **Lip-Sync Verification:** If the SNR threshold is breached but the Vision Engine confirms the candidate's lips are closed, the system flags the presence of unauthorized background assistance.

### 3. Decoupled Evidence Pipeline
Storing massive Base64 image strings directly in a database causes catastrophic payload crashes and exceeds standard document limits (e.g., MongoDB's 16MB limit).
* **Cloud Object Routing:** The Express.js backend intercepts massive evidence payloads, streams them securely to a Cloudinary CDN, and saves only the resulting lightweight `HTTPS` secure URL to the database.
* **Base64 PDF Generation:** Bypasses strict browser CORS policies and third-party firewall blocks by converting Candidate Resumes into native Base64 Data URIs for instant, secure rendering inside React Modals.

### 4. LLM-Powered Voice Interviewer
Candidates upload their PDF resumes to initiate a live technical interview.
* **Contextual Prompt Engineering:** The backend parses the raw PDF text buffer and injects it into a strict system prompt, forcing the LLM to ask highly specific, targeted questions based *only* on the candidate's actual projects.
* **Speech-to-Text & Text-to-Speech:** Features a fully interactive voice loop, allowing candidates to speak naturally while the AI generates and verbalizes follow-up questions in real-time.

### 5. Remote Code Execution (RCE) Sandbox
* Integrates with the Wandbox Compiler API to securely compile and execute candidate C++ code.
* Automatically evaluates standard output (`stdout`) against hidden test cases, returning granular runtime errors, compilation failures, and final DSA scores.

### 6. Role-Based Dashboards & Analytics
* **Recruiter Dashboard:** Features real-time search, sorting algorithms (Latest, Highest Score), and an interactive Evidence Modal with glowing loading states to decrypt and review cheating snapshots.
* **Candidate Dashboard:** Built with Recharts to visualize historical performance graphs, paginated data tables, and an embedded PDF viewer to review the exact resume used during Mock Interviews.

## 💻 Tech Stack

**Frontend**
* Next.js (React)
* Tailwind CSS (Styling & Responsive Design)
* Recharts (Data Visualization)
* WebRTC & MediaDevices API (Camera/Mic Access)
* Web Audio API (DSP)

**Backend**
* Node.js & Express.js
* MongoDB Atlas & Mongoose (NoSQL Database)
* Socket.io (Real-time synchronization)
* Cloudinary (Cloud Object Storage)
* Wandbox API (Code Compilation)

**AI & Machine Learning**
* TensorFlow.js (`coco-ssd` Object Detection)
* `face-api.js` (Facial Landmark Detection)
* LLM APIs (Dynamic Interview Generation)

## 🛠️ Local Installation & Setup

**1. Clone the repository**
```bash
git clone [https://github.com/yourusername/PrepMasterAi.git](https://github.com/yourusername/PrepMasterAi.git)
cd PrepMasterAi
```

```
# Install server dependencies
cd server
npm install
```


**2. Install Dependencies**
```
# Install client dependencies
cd ../client
npm install
```

**3. Run the application**
```
# Start the backend server (from /server)
npm run dev
```
```
# Start the frontend client (from /client)
npm run dev
```
